# Weather Mood

## Description

Weather Mood is a responsive web application that helps users discover activities based on the current weather in a selected city. Instead of only showing the forecast, the app suggests places to visit according to the weather conditions, making it easier to plan the day.

## Technologies Used

- React
- Vite
- React Router
- JavaScript (ES6+)
- CSS3
- OpenWeatherMap API
- Geoapify Places API

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/labcvi-24/weather-app-frontend.git

```

### 2. Navigate to the project folder

```bash
cd weather-app-frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Create a `.env` file

Add your API keys:

```env
VITE_OPENWEATHER_API_KEY=your_openweather_api_key
VITE_GEOAPIFY_API_KEY=your_geoapify_api_key
```

### 5. Start the development server

```bash
npm run dev
```
